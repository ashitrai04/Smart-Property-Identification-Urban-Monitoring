name=Building Delineator
qgisMinimumVersion=3.22
description=Individual building footprints from drone or satellite imagery, delineated by a model trained on Indian low-rise urban fabric.
about=Sends imagery or a drawn area to an Urbanly model server and returns one polygon per building - not a semantic mask. Built for dense terraced housing, where neighbours share walls and a mask merges a whole block into one shape. Footprints are returned already regularized to rectilinear outlines. The plugin itself contains no model: inference runs on the server you point it at, so QGIS needs no PyTorch and no GPU.

changelog=
  0.9.1  Water change shows a legend and obeys the opacity slider. The
         slider only ever drove the vector layer, so raster results sat
         opaque with no way to see through them, and the class key was
         filtered on a percentage that water change does not report, so
         every row was dropped and nothing said what the colours meant.
    0.9.0  Water change (2 epochs): pick the earlier image and the one to
         compare it with, both from the rasters open in QGIS. Both are
         clipped to the drawn area and sent together, so the server puts
         them on one grid. Water built over reads as encroachment, water
         gone to bare ground or vegetation as recession.
    0.8.2  Fix the class raster failing to write at the last step:
         GDAL will not set a palette after pixels are written.
    0.8.1  Land cover lists only the rasters open in QGIS, never the
         server catalogue, and refuses to run when none is open.
    0.8.0  Land cover (9 class) as a raster task: the class GeoTIFF is added
         to the map with its own colour table, exported with a CSV of class
         areas. Imagery picker - run on a server raster or on any raster
         open in QGIS, which is clipped and uploaded. Installable from the
         in-QGIS repository, so updates arrive without reinstalling a zip.
    0.5.0  Road extraction v2 added as a second checkpoint beside v1.
    0.4.0 Raster algorithm clips at 8 cm, not 12.5, which recovers
          buildings it was losing. AOI is an outline, and clears.
    0.3.1 Find the server automatically, so the plugin works on a
          machine that is not the one running it.
    0.3.0 Dock panel: draw an area on the map, choose the model and
          post-processing, watch buildings appear as they are found,
          adjust overlay opacity, export.
    0.2.0 Toolbar button and menu entry that open the algorithms directly.
    0.1.0 First release: two Processing algorithms.
