# Ranges, not pins, on purpose. This package is meant to be copied to a
# machine whose Python version nobody checked first, and a hard pin like
# numpy==1.26.4 has no wheel on Python 3.13 - pip then tries to compile it,
# needs a C toolchain, and the install fails on a machine that would
# otherwise have worked. Every range below has wheels for CPython 3.10-3.13
# on Windows, macOS and Linux, so no compiler and no GDAL install is needed.
#
# There is no torch and no CUDA here: this server does arithmetic on
# elevation rasters, not inference.
fastapi>=0.110,<1
uvicorn[standard]>=0.27,<1
numpy>=1.26,<3
scipy>=1.11
scikit-image>=0.22
rasterio>=1.3,<2
shapely>=2.0,<3
pyproj>=3.6
geopandas>=0.14,<2
pyogrio>=0.7
requests>=2.28
boto3>=1.28          # only used to publish the tunnel address to R2
